# denoize v0.76.0

## Highlights

- Added `denoize Neural`, a second CLAP effect with the independent stable ID
  `org.penguin425.denoize.neural`, while preserving the existing deterministic
  DSP effect and state identity.
- Added pinned causal GTCRN inference on one permanent worker. Model download,
  artifact verification, graph preparation, resampling, recurrent state, and
  inference never run on the host audio callback.
- Added preallocated 10 ms blocks, bounded lock-free input/result queues, an
  absolute frame/generation protocol, and a fixed twenty-four-chunk host latency.
  Callback tests prove zero post-activation allocation and injected worker
  stalls prove non-blocking latency-aligned fallback.
- Added sample-accurate bypass, mix, output gain, and overload selection;
  delayed dry is the default, with last-safe gain and silence explicit. Mono,
  stereo, f32/f64, and a reserved typed reference sidechain are advertised.
- Added a closed, path-free `denoize-neural-daw-session-v1` contract binding
  the exact model ID/SHA-256, scheduler policy, port layout, and parameters,
  plus CLI create/inspect/validate and measured-latency commands.
- Added a Desktop Neural contract panel, Draft 2020-12 schemas, malformed and
  no-clobber/symlink tests, generated CLI/JSON documentation, release assets,
  and crates.io package coverage.

## Real-time and model boundary

- Activation verifies the managed `gtcrn-dns3` artifact at upstream revision
  `3862c44808dca492ea5a8a145d2dc2a1028d08c8`, size 535,190 bytes, and SHA-256
  `b4718df6228e7bdf1a8a435cf98f838636eb2fd331acabf86ba87c5192ebcb87`.
  Missing, redirected, or changed model storage fails activation; a DAW process
  does not download or substitute weights.
- The callback performs no allocation, lock acquisition, filesystem/network
  I/O, logging, model inference, worker wait, or CLAP thread-pool request. A
  worker result must match the exact delayed input identity and safety bounds.
- `fixed-24x10ms-worker-v1` reports
  `24 * ceil(sample_rate * 0.010)` frames. Finite fractional CLAP sample rates
  are accepted, and an independent f64 delayed-dry impulse must match the
  reported frame exactly.
- The complete release-profile path measured RTF 0.567 over 100 consecutive
  reference blocks. The 240 ms budget covers the measured eleven-block
  resampler/WOLA startup plus scheduler headroom; slower machines remain
  bounded and use the selected overload fallback rather than blocking audio.
- The pinned official CLAP validator 0.4.1 passes both bundle descriptors:
  81 tests, 68 applicable successes, 13 capability skips, and no failures or
  warnings. CI also runs the actual managed graph on the permanent worker.

## Scope and compatibility

- This release is causal speech enhancement, not universal restoration,
  target-speaker extraction, AEC, or microphone-array beamforming. The
  reference sidechain is deliberately reserved until those typed semantics and
  leakage/double-talk gates exist.
- Hosts render the four stable Neural parameters. VST3, a custom editor, AUv3,
  and LV2 remain separate parity gates and are not claimed by this release.
- Existing CLI, DSP CLAP, preset/session, model, restoration, project, IPC,
  update, and automation contracts remain compatible.
- v0.76.0 application updates accept exact transitions from v0.74.0 and
  v0.75.0, with authenticated offline rollback assets for both.

## Highlights

- Added the reusable `BackendSession` API for finite audio. Fixed-shape model
  graphs remain prepared across files, VAD regions, CLI batch items, and
  desktop batch items; dynamic backends retain their most recently prepared
  shape.
- Added the common stateful `StreamingBackendSession` API for Classical,
  RNNoise, and GTCRN. WAV `--stream`, CLI live processing, and the desktop
  realtime page now share continuous denoiser, overlap, recurrent, resampler,
  and channel-mode state across chunks.
- Enabled the causal GTCRN backend for WAV streaming and realtime processing,
  including independent, stereo-linked, and mid/side modes. GTCRN streaming
  requires the managed or explicitly selected ONNX model; live GTCRN rejects
  VAD because a causally aligned VAD path is not yet available.

## Compatibility

- Existing finite-file and Classical/RNNoise streaming commands remain
  supported. The new session APIs and GTCRN streaming modes are additive.
- Because the denoize package version participates in the unchanged v3
  batch-resume recipe hash, v0.47 records are reported as `recipeChanged` after
  upgrading to v0.48. Existing outputs remain untouched unless `--force` is
  supplied. Regenerate once with `--force` to migrate the saved recipes;
  subsequent identical v0.48 runs skip normally.

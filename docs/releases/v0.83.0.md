# denoize v0.83.0

v0.83.0 implements the native safe baseline of Stage 30: typed
far-end-reference acoustic echo cancellation with explicit clocks and signed
delay, double-talk-safe adaptation, independently signed promotion evidence,
and exact-duration path-free output.

## Native AEC

- Added the `aec` feature and `denoize aec MICROPHONE FAR_END_REFERENCE OUTPUT`.
- Added explicit microphone/reference nominal rates, constant reference-clock
  offset, signed initial delay, and absolute route generation. Neither input is
  silently resampled without that mapping.
- Added normalized FFT cross-correlation for positive and negative bulk delay,
  with a minimum-overlap guard against short false peaks.
- Added `native-pfdnlms-v1`: partitioned frequency-domain normalized LMS,
  constrained partition updates, filter leakage/regularization, explicit
  double-talk adaptation freeze, and conservative residual suppression.
- Missing or low-confidence reference preserves the microphone. Reference,
  route, clock, delay, and non-finite-state discontinuities cold-reset all
  adaptive history. Output preserves exact microphone rate and frame count.

## Promotion and real-time boundary

- Added `AecSession`, preallocated exact-block `AecStream`, and an
  arbitrary-quantum `AecRealtimeAdapter` with one fixed block of latency.
  Processing allocates, locks, waits, logs, and performs file/network I/O zero
  times.
- The closed configuration binds block/tail/delay/analysis geometry, adaptation
  and leakage, activity/delay/double-talk thresholds, residual and gain floors,
  and normalized peak safety. Its canonical digest must match signed evidence.
- Promotion requires exactly 17 delay/drift/path/talk/impairment/transition
  strata; ERLE only in valid far-only regions; near-end attenuation and WAcc;
  far-end/double-talk/full-band AECMOS; exact duration; non-finite and stale
  reset output; reconvergence; <=20 ms latency; and blinded listening.
- Global gates require at least 100 real-device, nonlinear-device, and
  transition cases; 10,000 paced blocks; worst-case single-thread RTF <=0.5;
  and zero callback allocation/lock/wait/I/O/log, deadline, and stale-reset
  violations.

## Contracts and release integration

- Added `denoize-aec-promotion-evidence-v1` and `denoize-aec-report-v1`, schema
  parity tests, release-asset verification, and crates.io package checks.
- Reports bind evidence/configuration plus domain-separated microphone,
  reference, and output PCM identities; record explicit mapping, delay,
  geometry, latency, talk/adaptation/reset/clipping counts, and valid-region
  ERLE; and record zero filesystem paths.
- Added CLI parser and real-process tests for signed success, exact 1,603-frame
  output, negative scalar parsing, path privacy, and signature failure before
  audio decode or publication.
- Added the AEC guide, paper/artifact audit, JSON index, generated CLI reference,
  README overview, and roadmap status.

No neural AEC checkpoint is bundled. A learned nonlinear residual filter still
requires an authenticated package-v2 graph, immutable redistributable artifact,
complete corpus terms, native numerical vectors, and non-inferior protected-
stratum evidence. A host activating a plug-in reference port must additionally
prove stable routing, clock measurement, reset generation, and worst-case
scheduling on each promoted format.

# denoize v0.77.0

v0.77.0 delivers Stage 29: offline, fail-closed target-speaker extraction with
biometric enrollment privacy and independently signed promotion evidence.

## Target-speaker extraction

- Adds the `denoize target-speaker` CLI, Rust `TargetSpeakerSession`, and
  equivalent Desktop workflow.
- Accepts only a signed runtime package v2 whose finite stateless graph has one
  `audio` mixture input, one `enrollment` input, one matching extracted-audio
  output, and one calibrated `[absent, uncertain, present]` probability output.
- Authenticates every package component, provenance record, graph name/type/
  shape, selected precision profile, resource bound, and signed numerical
  vector before opening mixture or enrollment audio.
- Verifies separately signed promotion evidence and its exact package, source,
  checkpoint, licensed-corpus, raw-result, REAL-T, and TS-SUPERB bindings before
  inference.
- Publishes audio only for `accepted-present`. Target absence, uncertainty, or
  any geometry, finite-value, energy, peak, clipping, presence, or evidence
  failure leaves the requested audio path absent; no mixture, silence,
  candidate, or potentially wrong speaker is substituted.
- Adds a closed, path-free report with model/evidence identity, presence
  probabilities, signal measurements, gates, decisions, and accepted PCM
  bindings. Withheld candidates have no candidate/output digest.

## Privacy and evidence

- Mixture and enrollment are local regular files; the extraction path performs
  no network access.
- Decoded, mono, resampled, and float32 enrollment buffers are zeroized
  immediately after inference. Reports contain no enrollment PCM, embedding,
  digest, or path and retain only bounded input/model geometry.
- Promotion requires 22 explicit target-present/absent strata, at least 100
  target speakers, 100 interferers, two languages, calibrated target presence,
  target ASR and similarity, interferer similarity and word leakage, SI-SDR,
  DNSMOS-P808, exact finite output, and listening evidence.
- REAL-TSE 2026 findings are reflected directly: REAL-T and TS-SUPERB have
  independent result digests, target-activity and content gates constrain
  learned perceptual/identity scores, and target absence is never treated as a
  valid low-energy extraction.

## Distribution and validation

- Ships `denoize-target-speaker-report-v1` and
  `denoize-target-speaker-promotion-evidence-v1` schemas in GitHub Release and
  crates.io packages, with schema parity and fail-closed semantic tests.
- CI exercises a real signed two-input ONNX fixture for accepted, uncertain,
  invalid-evidence, graph-contract, numerical-vector, privacy, no-clobber, and
  publication behavior.
- No target-speaker model is bundled or added to the managed catalog. The
  audited WeSep, REAL-TSE baseline, WeSpeaker, TS-SUPERB, and MeanFlow-TSE
  artifacts do not yet provide one complete independently verified checkpoint
  redistribution, training-data, and protected-stratum evidence chain.

## Scope and compatibility

- Existing denoising, deterministic/universal restoration, DAW plug-in,
  package v1/v2, project, receipt, evaluation, IPC, update, and automation
  contracts remain compatible.
- v0.77.0 application updates accept exact transitions from v0.75.0 and
  v0.76.0, with authenticated offline rollback assets for both.
- Stage 29 v1 is whole-utterance and mono. Causal/DAW use remains gated on
  offline non-inferiority, authenticated recurrent-state/reset vectors,
  effective latency no greater than 100 ms, and the Stage 28 real-time callback
  matrix.
- Ordinary-drop zeroization does not prove erasure from operating-system cache,
  allocator copies, swap, crash dumps, or copies created outside denoize.

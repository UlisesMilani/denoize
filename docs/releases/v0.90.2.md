# denoize v0.90.2

v0.90.2 is a documentation-focused patch release that makes the project
easier to evaluate and navigate without changing its audio-processing
contracts.

## Changed

- Replaced the 2,138-line root README with a concise introduction covering
  installation, representative commands, supported workflows, safety, and the
  main documentation links.
- Added a matching Japanese README.
- Added a documentation index that groups the existing guides by task.
- Moved the consolidated CLAP and desktop guidance into focused documents so
  detailed operational and development information remains available without
  crowding the project front page.

# denoize v0.78.1

v0.78.1 publishes the Stage 28b VST3 reference gate after correcting the
cross-platform release build. The v0.78.0 tag remains an unpublished build
attempt and is never used as an updater source.

## VST3 3.8 bundles

- Ships ready-to-copy VST3 bundles for Linux x86-64, macOS Intel and Apple
  Silicon, and Windows x86-64, each with a checksum and per-artifact CycloneDX
  SBOM.
- Exposes both stable processors, `denoize` and `denoize Neural`, through the
  shared CLAP DSP, neural scheduler, state, and authenticated model boundary.
- Pins C++17 explicitly for the wrapper on every generator and runs the pinned
  Ardour 8.4 gate on its matching Ubuntu 24.04 image.
- Statically links the exact Rust CLAP entry, pins every wrapper and SDK
  revision, and rejects dynamic substitution from host, user, or system paths.

## Validation and evidence

- Both descriptors pass all 94 checks in the pinned official VST3 3.8.1
  validator and the complete process-format sample-rate matrix.
- A real Ardour process discovers, inserts, processes, saves, reloads, and
  tears down both descriptors while checking their latency contracts.
- Release assets include the validator and host reports, a closed signed host
  matrix, checksums, SBOMs, and Sigstore/SLSA provenance.
- Recoverable update bundles accept the two published predecessors, v0.76.0
  and v0.77.0; the unpublished v0.78.0 attempt is excluded.

## Scope

- The wrapper exposes f32 VST3 processing; it does not claim an internal f64
  VST3 path.
- Generic host parameter controls remain supported. The accessible custom
  editor is delivered by the separate Stage 28c release.
- The signed real-host claim is limited to the named Ardour build; proprietary
  hosts remain explicitly unclaimed.

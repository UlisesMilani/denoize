# denoize v0.84.0

v0.84.0 implements the safe deterministic baseline of Stage 31: offline
microphone-array enhancement with explicit geometry, authenticated promotion
evidence, calibrated multichannel WPE, conditioned mask-MVDR, and a declared
reference-channel fallback. Ordinary stereo and surround are never inferred to
be microphone arrays.

## Added

- Added `denoize array MICROPHONE_ARRAY OUTPUT` and the `array-enhance` alias.
  The required `--array-config`, `--promotion-evidence`, and
  `--promotion-evidence-key` controls are authenticated before audio is opened.
- Added `denoize array evidence verify` for independent Ed25519 evidence
  verification and human, compact JSON, or pretty JSON output.
- Added `MicrophoneArrayConfig`, `MicrophoneArrayGeometry`,
  `MicrophonePosition`, `MicrophoneArraySession`, and
  `MicrophoneArrayResult` to the public Rust API.
- Added explicit meters and right-handed x-forward/y-left/z-up semantics,
  unique channel IDs/positions, signed sample skew, gain/phase calibration, and
  an exact reference microphone identity for two through four channels.
- Added canonical configuration hashing. Matching channel/geometry permutations
  bind the same configuration and render equivalently.
- Added multichannel WPE dereverberation and bounded mask-estimated MVDR with
  diagonal loading, pivot/condition gates, finite checks, per-bin reference
  fallback, exact-duration overlap-add synthesis, and bounded peak output.
- Added fail-closed inactive-reference handling. Too few active microphones or
  an ill-conditioned bin preserves the declared reference rather than choosing
  another semantic target.
- Added bounded memory estimation covering decoded PCM, WPE, STFT spectra,
  covariance/solver state, synthesis, and output; the CLI includes these in
  `--max-memory` enforcement.
- Added `denoize-microphone-array-promotion-evidence-v1` and
  `denoize-microphone-array-report-v1`. Both closed schemas ship as GitHub
  release assets and in the crates.io package.
- Added schema semantics tests, CLI parsing tests, geometry/signature tests,
  exact-duration/finite-output tests, permutation-equivalence tests,
  inactive-reference tests, and singular-solver tests.
- Added the complete microphone-array guide, generated CLI reference, JSON
  contract documentation, research audit status, and roadmap status.

## Promotion boundary

Promotion evidence binds the implementation source, canonical configuration,
corpus manifest, objective result, and listening result. It requires the exact
bad-channel, permutation, clock-skew, diffuse/directional-noise, gain/phase,
moving-source, program-stereo, real-meeting, simulated-RIR, two-microphone, and
unseen-geometry strata. Per-stratum SI-SDR, WER, DOA, coloration, leakage, and
finite-output gates are combined with real-meeting/unseen/permutation coverage,
10,000 paced blocks, worst-case RTF, callback safety, deadline, and listening
gates.

## Deliberate limitations

- The release contains an inspectable offline WPE plus mask-MVDR baseline, not
  a jointly optimized or neural spatial beamformer.
- No SpatialNet, OnlineSpatialNet, DFSNet, DeFTAN-AA, or geometry-aware neural
  checkpoint is bundled. Audited projects do not yet provide the complete
  immutable redistributable weight and data-term chain required for promotion.
- Streaming neural and moving-source claims remain gated on a package-v2 model,
  numerical vectors, real-device evaluation, and a callback-safe worker bridge.
- The renderer accepts two through four synchronized channels; continuously
  changing inter-device clocks are outside this release contract.

## Release verification

The release workflow validates all Rust targets/features, both microphone-array
JSON contracts and semantic tests, the generated CLI reference, exact version
metadata, crates.io package contents, release asset inventory/checksums,
application-update rollback metadata, SBOMs, and provenance before publication.

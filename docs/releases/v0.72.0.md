## Highlights

- Added bounded, deterministic **denoize diagnose** analysis for additive
  noise, clipping, 50/60 Hz hum, clicks, reverberation, bandwidth limitation,
  short dropouts, wind/plosive energy, and lossy-codec risk.
- Added **denoize assess** for single-input native no-reference quality and
  before/after comparison. Comparison separately gates sample rate, channels,
  total presentation duration, new clipping, and new dropouts.
- Added explicit quality dimensions, estimator uncertainty, evidence,
  confidence, severity, and a recommended restoration pipeline. The MOS proxy
  is identified as a native triage estimate and never presented as human MOS.
- Added closed Draft 2020-12 diagnostic and assessment schemas, deterministic
  fixture validation, path-free JSON, option-before-I/O errors, bounded
  analysis, and stable Rust library APIs.
- Added the same diagnosis and assessment operations to the Desktop Evaluation
  page. Audio remains local and the WebView receives typed report objects only.
- Added the ordered Stage 24–33 restoration roadmap covering model package v2,
  deterministic repair, universal restoration, neural plug-ins, target
  speaker extraction, AEC, spatial processing, project v2, and SDKs.

## Compatibility

- Existing processing, recommendation, signed evaluation, project, model,
  receipt, update, and plug-in contracts are unchanged.
- The diagnostic and assessment v1 documents are new and reject unknown
  fields. Older denoize versions do not understand them.
- Analysis defaults to 12 seconds, accepts 1–60 seconds, and resamples the
  channel-mean analysis signal to no more than 48 kHz. Source-channel clipping
  is measured before mixing.
- v0.72.0 application updates accept exact transitions from v0.70.0 and
  v0.71.0, with authenticated offline rollback assets for both.

## Safety boundary

- Diagnosis and assessment never open a network connection, update a model
  catalog/cache, or expose a source pathname in JSON.
- The native quality score and MOS proxy are triage evidence, not release
  acceptance criteria. Signed reference metrics and human listening evidence
  remain authoritative.
- Schema v1 does not assess words, phonemes, speaker identity, language,
  prosody, or generated hallucinations. Before/after reports expose
  **semantic_fidelity_assessed: false** and warn against score-only acceptance.
- A changed sample rate, channel count, or presentation duration makes a
  comparison incomparable. New clipping or dropouts make it degraded.

## Highlights

- Completed bounded file-streaming parity with 20 ms VAD decisions, fixed
  five-second history, backend-latency alignment, and a 200 ms hangover/fade.
  VAD now preserves the exact presentation timeline without requiring a
  whole-file PCM allocation.
- Added fixed-memory two-pass EBU R128 loudness normalization and metadata
  preservation for regular-file, resumed, and stdin/stdout streaming. The
  analysis and verified encoding passes share bounded anonymous spools and
  continue to honor process-wide RAM and temporary-space admission.
- Added stateful DeepFilterNet and MossFormer2 file streaming. DeepFilterNet
  reuses one prepared 48 kHz runtime on a dedicated worker, while MossFormer2
  retains only its official four-second window and three-second stride. Both
  preserve exact input presentation length; the low-latency live path remains
  limited to Classical, RNNoise, and GTCRN.

## Compatibility

- Existing file and batch outputs, v3 batch journals, v1/v2 stream
  checkpoints, execution plans, signed receipts, and managed models remain
  compatible. Stage 15 adds no new checkpoint schema version.
- Streaming VAD, loudness, and metadata settings now participate in the same
  bounded resource and publication rules as other stream processing. A request
  that exceeds its RAM or temporary-space allowance fails before publication;
  existing output and restart state remain untouched.
- Because the denoize package version participates in the unchanged v3
  batch-resume recipe hash, v0.62 records are reported as `recipeChanged` after
  upgrading to v0.63. Existing outputs remain untouched unless `--force` is
  supplied. Regenerate once with `--force`; subsequent identical v0.63 runs
  skip normally.

## Compatibility

- Filesystem audio inputs must now resolve to regular files. FIFOs, directories,
  and device files are rejected before parsing; symbolic links remain accepted
  when their targets are regular files. Standard-input WAV (`-`) keeps its
  separate bounded buffering path.
- `--max-memory` is now a stricter per-input/per-worker cap on denoize-owned
  whole-file decoded PCM, explicitly accounted codec scratch space, and native
  metadata work. Whole-file processing has a 1 MiB floor. AAC decoding charges
  a conservative 128 MiB fixed allowance plus 64 KiB per encoded payload byte
  against the cap before decoder entry. Private allocations inside third-party
  codec libraries and allocator capacity rounding remain outside exact
  enforcement; concurrent workers each apply the cap.
- Because the denoize package version participates in the unchanged v3
  batch-resume recipe hash, v0.45 records are reported as `recipeChanged` after
  upgrading to v0.46. Existing outputs remain untouched unless `--force` is
  supplied. Regenerate once with `--force` to migrate the saved recipes;
  subsequent identical v0.46 runs skip normally.

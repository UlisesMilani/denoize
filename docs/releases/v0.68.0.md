## Highlights

- Added the first denoize DAW plug-in as a CLAP audio effect for Linux x86-64,
  macOS Intel and Apple Silicon, and Windows x86-64. It supports mono/stereo,
  f32/f64, in-place/out-of-place processing, sample-accurate automation,
  bypass, stereo linking, dry/wet mix, and output gain.
- Added one portable preset contract and one complete deterministic session
  contract shared by CLAP host state, the CLI, the library, and the Desktop DAW
  page. Factory presets are `speech`, `gentle`, and `music`; JSON import and
  export use bounded regular files and atomic no-clobber publication.
- Added fixed host latency reporting plus independent impulse measurement.
  `denoize plugin latency` fails if the measured first output frame differs
  from the reported `fixed-10ms-v1` frame count.
- Added four checksummed CLAP archives to the release evidence set. All 18
  installable artifacts receive CycloneDX SBOMs and tagged-workflow provenance.

## Compatibility

- CLAP is the only plug-in format in this release. VST3, Audio Unit, AAX, and
  LV2 hosts need a later format integration or a CLAP-capable bridge.
- The plug-in exposes host-rendered parameter controls and does not ship a
  custom in-host editor in v0.68.0. The Desktop DAW page manages the same
  portable preset/session files outside the host.
- Preset and session schema v1 reject unknown fields, unknown plug-in IDs,
  changed latency policies, and future schema versions. Host snapshots and
  standalone JSON use the same compact state bytes; older denoize versions do
  not understand these new files.
- The fixed latency is `ceil(sample_rate * 0.010)` frames, so the reported time
  can be slightly greater than 10 ms at sample rates where 10 ms is not an
  integer number of frames. Bypass preserves this delay so host compensation
  does not jump during automation.
- Because the denoize package version participates in the unchanged v3
  batch-resume recipe hash, v0.67.1 records are reported as `recipeChanged`
  after upgrading to v0.68.0. Existing outputs remain untouched unless
  `--force` is supplied. Regenerate once with `--force`; subsequent identical
  v0.68.0 runs skip normally.

## Real-time and release boundary

- Plug-in activation allocates every delay and DSP buffer. The audio callback
  performs no allocation, locking, filesystem or network I/O, or system calls.
  A counting-allocator regression processes 1,000 stereo blocks and requires
  zero callback allocations.
- CI and the tagged release workflow run the checksum-pinned official CLAP
  validator 0.4.1. Its 44-test suite produces 36 applicable passes, 8
  capability-based skips, no failures, and no warnings. State fuzzing,
  f32/f64, in-place/out-of-place, random block size, varying sample rate,
  parameter, reset/reactivation, and mono/stereo layout tests are included.
- Portable documents are limited to 64 KiB, reject symlink inputs, validate
  every finite parameter before publication, and never replace an existing
  destination unless `--replace` or the Desktop overwrite toggle is explicit.

# denoize v0.82.0

v0.82.0 completes the causal substage of Stage 29. It adds a fail-closed
recurrent target-speaker graph adapter, a bounded off-callback inference bridge,
dual offline/causal promotion evidence, exact-duration file rendering, and
closed release assets without bundling an unaudited speaker model.

## Causal extraction

- Added `denoize target-speaker causal` with authenticated model package,
  offline evidence, causal evidence, bounded decoding/model memory, atomic
  no-clobber audio/report output, and path-collision checks.
- Requires fixed equal frame/hop geometry, explicit zero-initialized recurrent
  state pairs, normalized absent/uncertain/present probabilities, signed
  reset/recurrent/flush vectors, signed latency no greater than 100 ms, and
  flush coverage for that latency.
- Produces the complete flush tail, removes only the authenticated algorithmic
  latency, resamples to the source rate, and preserves the exact source frame
  count. Absent, uncertain, warm-up, unsafe, and unsafe-flush blocks are
  time-aligned silence rather than mixture or unverified voice fallback.
- Zeroizes enrollment and concrete recurrent buffers on ordinary drop where
  their representations permit it. Reports contain bounded enrollment geometry
  but no enrollment samples, embedding, digest, or path.

## Real-time and evidence boundary

- Added a permanent-worker scheduler with a fixed 40-block pool, 16-block
  lock-free input/output queues, absolute generation/frame tokens, explicit
  overload, and late/stale-result discard. Callback submit, receive, and reset
  allocate, lock, wait, log, perform I/O, and infer zero times.
- Added signed causal promotion evidence that retains every offline hard limit
  and gates maximum regression across all 22 target-present/absent strata.
- Requires at least 100 perturbation-latency cases at no more than 100 ms;
  10,000 paced callback blocks with zero misses, overloads, or forbidden
  callback operations; and at least 100 cases for each presence, mismatch,
  reference-loss, late, and stale transition with zero false attribution.
- Requires both accepted signatures and exact package, source, checkpoint,
  offline-result, and stream-geometry binding before user audio is opened.

## Contracts and limits

- Added `denoize-causal-target-speaker-promotion-evidence-v1` and
  `denoize-causal-target-speaker-report-v1`; both ship as GitHub release assets
  and in the crates.io package and are covered by closed schema tests.
- Updated the research audit, roadmap, CLI reference, JSON index, README, and
  target-speaker guide with the causal policy and published API.
- No target-speaker checkpoint is bundled. Audited candidates still lack a
  complete artifact-level redistribution, training-data/consent, and protected-
  stratum evidence chain. The API is usable only with an operator-supplied
  signed package that passes both promotion layers.
- No CLAP, VST3, AUv3, or LV2 enrollment sidechain is claimed. Each format
  still needs separate consent, non-retaining state, automation, latency, and
  real-host evidence before it may expose causal target-speaker processing.

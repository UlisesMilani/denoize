# denoize v0.80.0

v0.80.0 completes the macOS portion of Stage 28d by shipping the existing
standard and Neural descriptors as a sandboxed AUv3 app extension. DSP,
parameter IDs, port semantics, fixed latency, fallback policy, and portable
state remain shared with the CLAP reference rather than being reimplemented.

## AUv3 delivery

- Added stable Audio Component identities `aufx/Dn01/Dnze` and
  `aufx/Dn02/Dnze` through the pinned clap-wrapper 0.16.0 and CLAP SDK 1.2.6
  commits.
- Added native Intel and Apple Silicon builds. Each archive contains one
  ordinary macOS app embedding the sandboxed `.appex`, which in turn embeds
  the exact signed `denoize.clap` used for component discovery.
- Kept VST3's static linkage and AUv3's signed embedded-CLAP linkage in
  separate CMake build directories so compile definitions cannot cross format
  boundaries.
- Applied one pinned, reverse-verifiable clap-wrapper compatibility patch for
  Xcode 15.4's strict Objective-C++17 rules: the microphone-authorization case
  has an explicit scope and weak/strong references use compiler-qualified
  `__typeof__` without shadowing `self`.
- Added explicit app/extension identifiers, Xcode app-extension product type,
  sandbox entitlements, nested signing verification, package layout checks,
  and checksums/SBOM/provenance integration.

## Self-contained neural model

- Bundled the pinned 535,190-byte GTCRN graph and its authenticated catalog
  provenance inside the nested CLAP resources so the AUv3 sandbox does not
  depend on a user cache it cannot access.
- Added macOS loaded-image resolution using `dladdr`. Explicit
  `DENOIZE_MODEL_DIR` remains authoritative; bundle resources precede the
  ordinary cache only when no override exists.
- Bundled bytes, size, SHA-256, catalog identity, and provenance are verified
  read-only before inference. Missing or corrupt evidence fails closed.

## Validation and evidence

- Apple's `auval` must register and pass both component identities.
- An independent AVFoundation host must find and instantiate both components
  out of process, allocate/reset/deallocate render resources, round-trip full
  state, and tear down cleanly.
- Each architecture publishes its raw `auval` and AVFoundation reports plus a
  closed `denoize-auv3-host-evidence-<tag>-<target>.json` record. One target-local
  Sigstore bundle binds all three files to the v0.80.0 source and trusted
  release workflow.

## Limits

- iOS builds, device provisioning, App Store packaging, and mobile hosts are
  not shipped.
- Proprietary DAWs and automated AU custom-view interaction are not claimed.
  The containing app opens `Dn01`; both `Dn01` and `Dn02` remain covered by the
  validator and AVFoundation lifecycle/state gates.

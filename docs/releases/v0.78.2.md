# denoize v0.78.2

v0.78.2 publishes the Stage 28b VST3 reference gate after correcting the
remaining Apple single-config CMake packaging path. The v0.78.0 and v0.78.1
tags remain unpublished build attempts and are never updater sources.

## Fixed

- Accepts both supported CMake release layouts when packaging a VST3 bundle:
  multi-config generators place `denoize.vst3` below `Release`, while the
  Apple Silicon hosted runner's single-config generator places it directly in
  the target build directory.
- Fails closed if neither layout exists, either candidate is a symbolic link,
  or both layouts exist and would make the release input ambiguous.
- Extends the archive-layout CI gate to exercise both the single-config Apple
  path and the multi-config Linux path without weakening explicit-bundle
  validation for Windows.

## VST3 release scope

- Ships ready-to-copy VST3 3.8 bundles for Linux x86-64, macOS Intel and Apple
  Silicon, and Windows x86-64, with checksums, CycloneDX SBOMs, provenance, and
  signed host evidence where the release matrix declares it.
- Exposes the stable `denoize` and `denoize Neural` processors through the
  shared CLAP DSP, worker, state, latency, and authenticated model boundaries.
- Preserves the pinned wrapper/SDK revisions, C++17 requirement, official VST3
  validator gate, and pinned Ardour real-host gate.

## Updates

Recoverable update bundles continue to accept the two published predecessors,
v0.76.0 and v0.77.0. Neither unpublished v0.78.0 nor v0.78.1 is accepted as a
rollback source.

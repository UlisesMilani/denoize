# denoize v0.75.0

## Highlights

- Added fail-closed universal speech restoration with a separate Rust API,
  `denoize universal` CLI, and Desktop workflow for noise, reverberation,
  clipping, bandwidth limitation, codec distortion, packet loss, and wind.
- Added an authenticated BSRNN package-v2 adapter. It requires the exact signed
  48 kHz complex spectral contract, verifies component hashes and graph
  semantics, and executes selected-runtime numerical vectors before opening
  user audio.
- Added conservative clean-input bypass and private-candidate selection. A
  candidate is published only after geometry, finite-sample, energy, peak,
  newly introduced clipping, silence injection, and native quality gates all
  pass; otherwise decoded input is published unchanged.
- Added closed, path-free restoration reports and exact-coverage RLE change
  masks binding input/candidate/output PCM, package, public key, source,
  checkpoint, profile, and mask digests.
- Added separately signed promotion evidence with 20 protected strata, nine
  content/speaker/quality/output/performance metrics per stratum, and bounded
  human-listening requirements.
- Added Draft 2020-12 schemas, malformed and unsafe-mode tests, signed-package
  CLI execution, tamper/no-clobber/path-leakage coverage, Desktop controls,
  detailed research and operator documentation, release assets, and crates.io
  package checks.

## Trust and execution boundary

- Discriminative models are the only primary/default family. Hybrid and
  generative models require both `--experimental` and `--render-role alternate`;
  they cannot be silently selected as a primary render.
- Runtime package v1 and raw ONNX files are rejected by universal restoration.
  The selected v2 package, Minisign key, model component, graph, precision
  profile, provenance, license notice, and numerical vectors fail closed.
- The model session and its signed resource reservation are admitted and
  prepared before input decode. Decode, candidate, diagnostics, mask, model,
  and metadata memory remain under the explicit CLI/Desktop ceiling.
- Universal restoration performs no network access, archive extraction,
  checkpoint deserialization, script execution, or model download. Input,
  package, key, output, report, and mask aliases are rejected and destinations
  retain no-clobber defaults.
- Existing raw BSRNN use remains available outside the universal path for
  compatibility. Existing denoising, deterministic restoration, diagnosis,
  assessment, project, model, DAW, IPC, update, and automation contracts remain
  compatible.
- v0.75.0 application updates accept exact transitions from v0.73.0 and
  v0.74.0, with authenticated offline rollback assets for both.

## Model and evidence boundary

- No official URGENT or UniPASE checkpoint is bundled in the crate, GitHub
  release, Desktop app, or managed catalog. Source-code licensing, checkpoint
  page metadata, dependency weights, and every training-dataset term are
  independent redistribution gates.
- Package authentication proves bytes and declared provenance, not that a model
  is beneficial, licensed correctly, or faithful to words, phonemes, prosody,
  facts, or speaker identity.
- Native signal gates are rollback protection, not semantic assurance. Reports
  explicitly record semantic, speaker, and promotion assessment as false for a
  single render. Promotion requires independently signed stratified evaluation
  and listening evidence for the exact package digest.
- Output encoder quantization occurs after candidate selection; PCM digests,
  masks, and changed-sample counts describe the in-memory result before
  encoding.

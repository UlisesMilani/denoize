# denoize v0.81.0

v0.81.0 completes Stage 28e by shipping direct Linux x86-64 LV2 adapters for
the existing DSP and Neural effects. The adapters reuse the shared processing,
parameter, latency, fallback, model-verification, and portable-state contracts,
while implementing LV2-native ports, URIDs, Atom/Patch automation, State, and
Worker lifecycle.

## LV2 delivery

- Added stable descriptors
  `https://github.com/penguin425/denoize#lv2-dsp` and
  `https://github.com/penguin425/denoize#lv2-neural`, with 13 and 16 ports.
- Added a self-contained `denoize.lv2` bundle containing the pinned GTCRN graph
  and authenticated provenance. Host activation performs no network access.
- Preserved 480-frame DSP and 11,520-frame Neural latency at 48 kHz. Neural
  creates no private thread and delegates inference only to the host Worker.
- Added in-place-safe raw audio-port traversal without overlapping Rust
  references, including a regression test with aliased input/output buffers.

## Automation and state

- Ordinary control ports provide block-rate values. An optional Atom Sequence
  accepts at most 256 frame-timestamped Patch Set events per callback for
  sample-accurate bypass, mix, gain, fallback, and related controls.
- Invalid URIDs, unknown properties, non-finite values, out-of-range values,
  and events outside the current block fail closed or are ignored without
  extending callback work.
- DSP and Neural publish the shared closed JSON through the LV2 State
  interface as portable POD strings. The compatibility descriptor accepts
  zero caller flags used by Ardour while keeping each stored property's POD
  and portable flags intact.

## Validation and evidence

- Official LV2 1.18 tools validate all Turtle restrictions; Lilv discovers both
  descriptors and offline-processes DSP while correctly delegating the Neural
  Worker case to a Worker-capable host.
- Pinned Jalv 1.6.8 and JACK exercise both descriptors at 48 kHz/480 frames,
  including the Neural Worker schedule/response path and clean teardown.
- Pinned Ardour 8.4 creates a session, processes both descriptors, verifies
  exact latency, persists both state properties, reloads in a fresh process,
  processes again, and tears down without State interface errors.
- `denoize-lv2-host-evidence-v1.json` binds the tagged source, dependencies,
  descriptor contracts, three report hashes/sizes, claims, and limitations.
  A Sigstore bundle attests the JSON and every bound report.
- The LV2 archive is included in the release SBOM/provenance manifest and the
  public release asset verifier rejects missing, empty, unexpected, mismatched,
  or unattested files.

## Limits

- The release target is Linux x86-64. Other architectures and operating
  systems are not claimed.
- Audio ports are single precision. Double-precision processing is not claimed.
- Hosts use generic parameter interfaces; no LV2-specific custom editor ships.
- `lv2bench` does not provide the Worker feature needed by Neural, so the
  release uses Jalv for that real-host gate. Proprietary hosts remain untested.

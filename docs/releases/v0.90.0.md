# denoize v0.90.0

v0.90.0 implements Stage 37: fail-closed causal preserve/remove for one sound
selected from an authenticated finite class catalog.

## Added

- Added a dedicated recurrent runtime package-v2 adapter for fixed mono-center
  or ordered stereo blocks, immutable one-hot query input, same-geometry target
  and residual outputs, normalized absent/uncertain/present output, and one or
  more exact float32 or int64 state pairs.
- Added signed `causal-reset`, `causal-recurrent`, and `causal-flush` graph
  vectors; deterministic zero-state reset; bounded typed snapshot/restore;
  generation invalidation; complete latency removal and flush handling.
- Added `CausalTargetSoundSession`, streaming block decisions, exact
  `input - target` residual construction, source-clock publication masking,
  preserve/remove file rendering, and path-free reports.
- Added the fixed-pool `CausalTargetSoundRealtimeScheduler`. Its callback-side
  submit, receive, reset, and conservative fallback use preallocated buffers,
  bounded lock-free queues, and atomics while inference remains on one
  permanent worker.
- Added `denoize target-sound causal` and causal evidence verification. The CLI
  authenticates the package, query, accepted offline evidence, causal evidence,
  graph, and memory limits before decoding user audio, then stages target,
  residual, selected output, and report with selected output committed last.
- Added separately signed causal promotion evidence. It reproduces the exact
  offline catalog and fourteen-stratum metric matrix, enforces per-metric
  non-inferiority and hard limits, binds reset/snapshot/flush/recombination
  results, requires three named-device end-to-end measurements at no more than
  100 ms, and requires zero-violation callback and transition audits.
- Added closed causal evidence, render-report, and portable-snapshot JSON
  Schemas; real-ONNX state tests; source-clock conservation, fallback,
  snapshot, realtime, schema, CLI, crate-package, and release-asset checks; and
  updated paper/artifact research and roadmap documentation.

## Safety boundary

Every causal block publishes a complete decomposition. Only
`published-present` may expose the model target; its residual is derived from
the input. Absent, uncertain, warm-up, unsafe, flush-withheld, failed, late,
stale, or overloaded blocks publish target silence plus the untouched input.
There is no partial semantic-removal fallback.

A publication mask follows latency removal and sample-rate conversion. Source
samples that touch a withheld model interval or fail the filtered mask are
forced to the conservative decomposition, closing semantic bleed across chunk
and resampler boundaries. Reports require zero partial-removal fallbacks and
record the number of source-clock frames withheld.

The callback API does not allocate, lock, wait, infer, log, or perform I/O.
Pool/queue exhaustion and missing results are explicit and require the provided
conservative fallback. A generation or frame discontinuity resets recurrent
state at the exact next frame; all older results are rejected.

## Research and distribution boundary

Waveformer motivates the fixed one-hot causal architecture; Semantic Hearing
motivates binaural spatial gates; AudioSep remains an open-language comparison.
Their reported quality, runtime, and latency are not denoize measurements.

Frozen upstream source audits still do not provide a converted graph with the
complete checkpoint, dependency, training/evaluation-data redistribution chain
and signed Stage 36 plus Stage 37 evidence. This release therefore bundles no
target-sound model, checkpoint, dataset, or catalog and makes no upstream
quality or real-time claim. Open-language and audio-visual extraction remain
separate future gates.

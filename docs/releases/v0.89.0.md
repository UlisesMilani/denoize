# denoize v0.89.0

v0.89.0 implements Stage 36: fail-closed offline preserve/remove for one sound
selected from an authenticated finite class catalog.

## Added

- Added explicit runtime package-v2 `query` input and `residual` output roles,
  with closed schema/Rust validation and rejection of natural-language tensor
  roles.
- Added a dedicated finite, stateless target-sound adapter with fixed
  `[1,C,W]` audio, `[1,K]` one-hot query, same-geometry target/residual, and
  ordered absent/uncertain/present outputs. Mono-center and ordered stereo L/R
  are the only channel contracts.
- Added `TargetSoundQuery`, `TargetSoundSession`, preserve/remove configuration,
  overlapping-window inference, calibrated absence decisions, exact
  source-clock residual construction, bounded memory estimation, and
  path-free reports.
- Added graph and publication recombination, finite sample, exact geometry,
  target/residual peak and energy, stereo correlation, and Mid/Side energy
  gates. Absent, uncertain, and failed candidates return no audio values.
- Added `denoize target-sound`. Query, target, residual, selected-output, and
  report paths are explicit. Accepted float32 WAV artifacts are fully staged
  and committed with the selected output last; withheld jobs publish only the
  report and never substitute the source mixture.
- Added signed package/config/catalog promotion evidence with full artifact,
  checkpoint, training/evaluation data, and license identities; fourteen fixed
  presence, class-confusion, protected-foreground, transient/tonal,
  unseen-domain, and binaural-spatial strata; mandatory present/absent coverage
  and worst-case error bounds for every catalog class; and objective plus
  listening gates.
- Added closed query, evidence, and report JSON Schemas, semantic and real-ONNX
  integration tests, generated CLI reference, crate packaging checks,
  release-asset verification, roadmap status, product documentation, and a
  paper plus immutable artifact/license audit.

## Safety boundary

Open text is never accepted or sent to the graph. The complete ordered catalog,
revision, class IDs, and selected index are authenticated, and any change after
session preparation fails before inference. The model's target plus residual is
checked, while the publishable source-clock residual is defined exactly as
`input - target`.

Only `accepted-present` can publish target, residual, or mode-selected output.
Authentication, package, graph, and inference errors fail before publication.
Once candidate evaluation is reached, target absence, uncertainty, or any
conservation, signal, geometry, peak, energy, or stereo-spatial failure
publishes a report alone. No model, checkpoint, class catalog, or dataset is
bundled.

## Research basis

Waveformer's causal one-hot design motivates the finite catalog and later
streaming track. AudioSep demonstrates the value and additional prompt/data
failure surface of open-language separation, which remains outside this
release. Semantic Hearing motivates explicit binaural ITD/ILD and spatial
preservation gates. Upstream runtime and quality results are not represented as
denoize measurements.

The Waveformer, Semantic Hearing, and AudioSep code, checkpoint, and dataset
surfaces were audited separately at frozen source revisions. Their repositories
publish useful code, but none currently supplies a frozen converted graph with
the complete checkpoint/training/evaluation redistribution chain and signed
Stage 36 evidence. v0.89.0 therefore ships no upstream weights and makes no
upstream quality or real-time claim.
